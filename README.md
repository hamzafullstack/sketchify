# Sketchify

A browser-based Etch-a-Sketch style drawing application built with HTML, CSS, and JavaScript. Sketchify lets you create a customizable grid and draw on it by hovering over the cells.

## Features

* **Generate different grid sizes:**
  * 16 × 16
  * 32 × 32
  * 64 × 64
* Draw by hovering over grid cells
* RGB color mode
* Reset the grid with one click
* Simple and responsive interface
* DOM-based grid generation and interaction

## Built With

* HTML5
* CSS3
* JavaScript
  * DOM Manipulation
  * Event Listeners

## How It Works

1. Select a grid size.
2. Sketchify generates the selected grid dynamically.
3. Hover over the cells to draw.
4. Choose RGB mode for randomized colors.
5. Use Reset Grid to clear the drawing.
